# Token Current brand assets

- `icon.svg`: full-color square app icon, with transparent outer padding.
- `wordmark-light.svg`: dark lettering for a light background.
- `wordmark-dark.svg`: light lettering for a dark background.
- `mark-monochrome.svg`: one-color arrow mark.
- `banner.svg`: repository and project header.

The cyan upward arrow and amber downward arrow represent token flow. Keep their relative size and spacing, use a single color for monochrome contexts, and leave at least one arrow-stroke width of clear space around the mark. These are original vector assets; the macOS packaging script draws the same icon natively and exports its `.icns` and PNG versions. The release brand kit contains both vectors and native exports. No usage data is depicted in the decorative banner traces.
